# Brief explanation on Java 

Java is a platform independent, High level, Object oriented language 

Java language, have 3 main components 
1. JVM : Java Virtual Machine 
JVM helps in executing the byteCode, which is a platform independent code, can be run on any platform. 

2. JRE ( Java Runtime Environment )
JRE provide support for runtime execution for running the java programs. 
JRE consists of JVM along with set of libraries required for running the applicaiton. 

3. JDK ( Java Development Kit ) 
JDK is a entire development kit with JRE & JVM, which includes java compiler (helping in compiling & converting the java code to byte code), java debugger & Javadoc.  


**ByteCode**
- Bytecode is a machine readable code, which JVM executes. 
- When we run the application/program, JVM converts our program from `.java` -> `.class` file, this `.class` consists of code readable by machines.

**What does “hat does “write once, run anywhere””**
- When we run the Java application, a series are executions happens behind the seen.first the JVM converts the java source code to byte code using `javac` command
- This generated bytecode is then executed by JVM. The interesting fact is that, we can transfer this file (`.class` file) to any machine either, windows, mac or linux. 
- As long as, it have JVM installed, we can run this program, irrespective of the machines architecture. 
- Thats what it means by “write once, run anywhere**
